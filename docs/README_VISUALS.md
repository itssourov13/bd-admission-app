## Four Android showcase graphics

The source captures were supplied in `/home/kali/screenshort/bd-admission-apk-preview/` on 2026-11-18. Each original was 1220×2712 JPEG. The source screen pixels were preserved; the design adds a consistent dark promotional background, the existing app mark/wordmark, short feature copy and a restrained phone frame. The screenshots were scaled for presentation, not re-created or edited inside the phone display.
